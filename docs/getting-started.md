# Getting started

## Make a first export

1. [Install Claude Export](installation.md), then open a conversation on [claude.ai](https://claude.ai/).
2. Start with a short conversation containing sample text so you can check the result safely.
3. Use the inline Export control or open the toolbar popup.
4. Choose the latest response or full conversation and a format such as Markdown or Word/DOCX.
5. Save or copy, then inspect the output for completeness and sensitive information before sharing it.

Artifacts are included by default in the publicly documented workflow. Thinking is optional; enable it only if you want it in the exported document. Exact labels and previews can vary by installed version.

For a public illustrated walkthrough, see [How it works](https://claude.export.anhbui.dev/how-it-works). Website screenshots may show newer controls; check the [changelog](../CHANGELOG.md).

## Activate or restore Pro

After checkout, keep the success page open to allow automatic activation in that browser. To recover access in another browser profile, open the extension's purchase-restore option and use your purchase email and one-time code privately. Follow the [official activation guide](https://claude.export.anhbui.dev/activate) if activation does not finish.

The website describes up to three devices per license. Use the management link in your purchase email to manage activations or an eligible subscription. Email [support@anhbui.dev](mailto:support@anhbui.dev) if access remains unresolved; never share a license key, verification code or management link publicly.
