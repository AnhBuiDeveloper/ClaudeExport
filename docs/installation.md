# Installation

## Install from an official store

- **Chrome:** [Claude Export in the Chrome Web Store](https://chromewebstore.google.com/detail/claude-export-to-pdf-docx/eppnfcohgdbnmnekhfcpgokapbggmfde)
- **Microsoft Edge:** [Claude Export in Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/claude-export-to-pdf-doc/cmkoamjlhidmbdgamojbkjllgmbbielg)

1. Open the listing in the matching browser and choose its installation action.
2. Review the permissions shown by your browser and confirm installation.
3. Open the browser's extensions menu and pin Claude Export if you want quick toolbar access.
4. Sign in to [claude.ai](https://claude.ai/) and open a conversation. Reload an already-open Claude tab after installation.
5. Use an inline Export control or the toolbar popup to begin.

This repository does not distribute extension ZIPs or source builds. Use the stores for installation and updates. Free core exports do not need a Claude Export account; accessing your Claude conversations still requires your Claude session.

## Check the installed version

Visit `chrome://extensions` or `edge://extensions`, find Claude Export and open its details. Browser-managed updates can arrive at different times. Compare with [release status](../CHANGELOG.md), rather than assuming the website's latest announced workflow is installed.

## Remove the extension

Use the browser's extension-management page to remove it. Preserve any files and local archive data you need first: removing an extension or browser profile may remove its local data. Removal does not cancel a paid subscription; use the purchase email's management link or contact [support](../SUPPORT.md).
