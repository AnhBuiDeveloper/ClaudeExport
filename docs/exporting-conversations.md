# Exporting conversations

## Choose the content

- **Latest response:** keep a single useful answer.
- **Full conversation:** keep the available questions and answers together.
- **Custom range (Pro):** choose only the messages you need using the controls in your installed version.

Keep artifacts enabled if you want supported code and documents alongside answers. Include thinking only when needed. An export cannot guarantee content that Claude does not make accessible to the extension.

## Choose a format

| Format | Typical use | Plan |
| --- | --- | --- |
| PDF | Read or share a fixed document | Free core export |
| Word / DOCX | Continue editing a document | Free core export |
| Markdown | Notes, text-based knowledge tools and code | Free core export |
| TXT | Plain text without document styling | Free core export |
| Clipboard | Paste into another application | Free core export |
| HTML | A structured browser-readable document | Pro or eligible trial |
| JSON | Structured conversation data | Pro or eligible trial |
| ZIP | Bundle supported bulk exports | Pro or eligible trial |

Scope, document controls and trial availability can affect eligibility. Read [Free vs Pro](free-vs-pro.md).

## Check the result

Review headings, tables, code, artifacts and images before relying on the file. Complex layouts and content availability can vary. Redaction is a Pro document tool, not a substitute for your review before sharing.

Pro also offers templates and document controls such as cover pages, headers and a table of contents. Use the options actually present in your installed version.

## Newer PDF and image workflows

The website's **scheduled 1.2** guides describe searchable PDF through native browser printing, visual selection, and missing-image recovery for PDF/Word. These are not confirmed available in both stores; see [release status](../CHANGELOG.md).

If your installed version provides native printing, choose **Save as PDF** in the browser's print dialog. Opening that dialog does not confirm a file was saved. If your version offers image recovery, review the requested site permission before allowing access, or use the available retry, local replacement or skip option. Layout and font rendering can vary by browser and document viewer.
