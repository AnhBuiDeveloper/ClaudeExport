# Free vs Pro

The Chrome listing showed **1.1.1** on **22 October 2026**. The website already describes scheduled **1.2** behavior. The comparison below keeps that distinction explicit; Edge's published version is unconfirmed. See [release status](../CHANGELOG.md).

## Published 1.1.1 product offering

| Capability | Free | Pro |
| --- | --- | --- |
| Core formats | PDF, DOCX, Markdown, TXT, clipboard | Included |
| Individual responses | Unlimited | Included |
| Full-conversation file exports | Five per rolling 30 days | Unlimited |
| Default attribution | Saved Free files carry a watermark; clipboard text does not | No forced watermark |
| Trial | Five Pro trial exports per install, no card required | Not needed for purchased access |
| Advanced formats | Eligible trial exports | HTML, JSON and ZIP |
| Custom message ranges | Eligible trial exports | Included |
| Templates, redaction and document controls | Eligible trial exports | Included |
| Bulk ZIP export and Send to Notion | Pro features; check the installed trial prompt for eligibility | Included |

Trial use and remaining allowance are shown by the extension. Do not assume a newer website rule applies to your installed version.

## Scheduled 1.2 changes described by the website

These are announced rules, **not confirmation of store publication**:

- Basic individual-response files lose the default watermark; Free full-conversation files keep attribution.
- Free includes five full-conversation downloads/copies per rolling 30 days, alongside unmetered basic native PDF printing.
- Advanced native PDF requires verified Pro; PDF is excluded from the five advanced trial downloads/copies.
- Eligible non-PDF trial credits are charged after confirmed downloads/copies.
- Pro adds user-assisted full/incremental backup and an optional local searchable archive.

See [backup and archive](backup-and-archive.md) before relying on those workflows. Google Docs is conditional on a configured, available OAuth connection, not promised in current store builds.

## Buying, restoring and cancelling

The [pricing page](https://claude.export.anhbui.dev/pricing) offers monthly, yearly and one-time Pro options. Check it for current prices, discounts and terms rather than relying on a copied price here.

Checkout can activate the purchasing browser automatically. Restore privately using the purchase email and a one-time code. Eligible subscriptions can be cancelled at period end through the purchase email's management link. Uninstalling does not cancel a subscription.

For purchase, billing or activation problems, email [support@anhbui.dev](mailto:support@anhbui.dev). Do not attach purchase records, license tokens or payment details to public issues.
