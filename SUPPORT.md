# Support

## Choose the right channel

| Need | Where to go |
| --- | --- |
| Reproducible product bug | [Bug report form](https://github.com/AnhBuiDeveloper/ClaudeExport/issues/new?template=bug_report.yml) |
| Product improvement | [Feature request form](https://github.com/AnhBuiDeveloper/ClaudeExport/issues/new?template=feature_request.yml) |
| Incorrect or missing instructions | [Documentation form](https://github.com/AnhBuiDeveloper/ClaudeExport/issues/new?template=documentation.yml) |
| General product feedback | [Community discussions](https://github.com/AnhBuiDeveloper/ClaudeExport/discussions) |
| Activation, purchase, account or billing | [support@anhbui.dev](mailto:support@anhbui.dev) |
| Suspected vulnerability | Follow [SECURITY.md](SECURITY.md); email privately |
| Privacy or data request | [support@anhbui.dev](mailto:support@anhbui.dev) |

## Before reporting

1. Check your installed extension version and browser version.
2. Reload the Claude tab, reopen a conversation and try a simple export using non-sensitive sample text.
3. Check the [changelog](CHANGELOG.md) for version-dependent behavior and the [troubleshooting guide](docs/troubleshooting.md).
4. Search [existing issues](https://github.com/AnhBuiDeveloper/ClaudeExport/issues) for the same problem.

## Useful diagnostics

Provide a short summary, steps using invented sample content, expected and actual results, browser and version, extension version, operating system, and export format or feature. Include only the visible, sanitized error message or support reference if relevant.

An optional screenshot should be cropped and inspected for private text, names, URLs and browser tabs. Prefer a fresh reproduction with sample content. Do not upload raw console logs, network captures, exported conversations or backup files to public issues.

## Keep private information private

Issues, pull requests and discussions are public. Never post conversation contents, purchase records, customer email addresses, passwords, verification codes, license tokens, integration tokens, private management links or payment details. Do not send passwords, tokens or full card information by email either.

For account-specific or billing problems, email **support@anhbui.dev** from the purchase email if possible. Describe the problem and affected browser; support can guide any further private verification. No response-time guarantee is made here.

If something sensitive was posted accidentally, remove it where possible and contact support privately. If a credential was exposed, use the issuing service's revocation process; deleting a post alone does not invalidate it.
