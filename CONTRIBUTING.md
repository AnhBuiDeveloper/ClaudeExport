# Contributing

Thank you for helping improve Claude Export's documentation and user experience.

The extension is proprietary software. This repository contains public product documentation and community support resources; source-code contributions to the extension are not supported here.

## Welcome contributions

- Clear documentation corrections and broken-link fixes.
- Reproducible bug reports using non-sensitive sample content.
- Feature suggestions with a concrete workflow and intended benefit.
- Translation feedback and usability suggestions.

Use the [issue forms](https://github.com/AnhBuiDeveloper/ClaudeExport/issues/new/choose), or open a pull request for a documentation correction. For a larger documentation change, explain the intended scope in an issue first. Keep each pull request focused, check relative links and distinguish published store features from scheduled announcements.

Do not submit application code, copied proprietary material, extension packages, private conversations, screenshots with personal information or customer records. Do not add a software license that implies the proprietary extension is open source. Public visibility alone does not grant a source-code license.

Keep feedback respectful, specific and helpful. Do not post another person's personal information. Reports involving account, billing or private information belong at [support@anhbui.dev](mailto:support@anhbui.dev); suspected vulnerabilities follow [SECURITY.md](SECURITY.md).
