# Claude Export

**Keep useful Claude conversations as readable documents.**

Export individual responses or full conversations to PDF, Word and Markdown in Chrome and Microsoft Edge. Keep headings, tables, code and supported artifacts together for notes, research and handoffs.

**[Install for Chrome](https://chromewebstore.google.com/detail/claude-export-to-pdf-docx/eppnfcohgdbnmnekhfcpgokapbggmfde)** · **[Install for Edge](https://microsoftedge.microsoft.com/addons/detail/claude-export-to-pdf-doc/cmkoamjlhidmbdgamojbkjllgmbbielg)** · **[Official website](https://claude.export.anhbui.dev/)**

This is the official public documentation and community repository for Claude Export by AnhBuiDeveloper.

The extension is proprietary software. This public repository contains product documentation and community support resources, not the extension's source code.

## What you can do

- Save a useful answer or an entire conversation without leaving Claude.
- Create PDFs, editable Word documents, Markdown or plain text, or copy to the clipboard.
- Keep supported artifacts with the answer and choose whether to include Claude's thinking.
- Use Pro for custom message ranges, advanced formats, document controls, bulk ZIP exports and optional Send to Notion.
- Find guidance here for exports, troubleshooting and version-dependent backup and archive workflows.

**Availability:** On 22 October 2026, the Chrome listing showed **1.1.1**. The website labels **1.2.0** a scheduled release; its searchable native PDF, incremental backup and searchable local archive workflows are documented separately and are not confirmed available in both stores. Edge's current version has not been independently confirmed. Check your installed version and the [changelog](CHANGELOG.md).

## Start in three steps

1. Install from your browser's official store above and open a conversation on [claude.ai](https://claude.ai/).
2. Use the inline Export control or open Claude Export from the browser toolbar.
3. Choose the response or conversation, select a format, then save or copy the result.

See the [official workflow walkthrough](https://claude.export.anhbui.dev/how-it-works) for public product illustrations. Controls shown on the website may reflect a newer version.

## Privacy and your content

Standard file exports are created locally in your browser; conversation content is not sent to the Claude Export service to generate them. Optional Send to Notion sends the selected content directly to your Notion workspace. Licensing, purchases, support and product events are separate from local document creation. Any available Google Docs connection is optional and sends chosen content to Google; do not assume it is enabled in your store build.

Read [Privacy and data](docs/privacy-and-data.md) and the [official Privacy Policy](https://claude.export.anhbui.dev/privacy). Review files before sharing them: local processing does not remove sensitive content automatically.
